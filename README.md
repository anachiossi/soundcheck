# soundcheck

Offline-first wireless-mic assignment app for film sets: schedule by day/week, mic tables per scene,
shareable images of scenes, day sheets and TX cheat sheets. Works with no signal once installed.

No build step: open `index.html` through any web server. See `docs/HOW_IT_WORKS.md`.
Film data is not in this repository.
